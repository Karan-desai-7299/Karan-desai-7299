| | |
|---|---|

| **Security** | 6-digit OTP ride verification to prevent ride-start spoofing |

</details>

</details>

<details>
<summary><b>🎓 SnapClass</b> — AI-Powered Classroom Attendance System</summary>
<br/>

An AI attendance platform replacing manual roll-calls with face recognition and voice recognition, backed by a real-time Supabase database.

| | |
|---|---|
| **Stack** | Streamlit, Python, Flask, HTML, CSS, JavaScript, Supabase, dlib, Resemblyzer |
| **Scale** | Dual biometric pipelines (Face + Voice), QR-based multi-subject enrollment |
| **Performance** | Embedding-based matching (SVM classifier) — no raw biometric storage |
| **Security** | Embedding-only storage (no raw photo/audio retained), mandatory human review before any save |
| **Impact** | Two decoupled deployments — Streamlit ML app + independent Flask marketing site on Vercel |
| **Repository** | [`View Source →`](https://github.com/Karan-desai-7299/SnapClass-Making-Attendance-Faster-using-Ai) |

Every AI-driven attendance run — whether facial or voice-based — surfaces a review table before anything is committed to the database, ensuring a human always confirms an AI decision. Debugged real production issues including GPU-dependency bloat during deployment and Python version incompatibilities with scientific computing wheels.

</details>

<details>
<summary><b>📄 AI Resume ATS Scorer</b> — Semantic Resume-to-JD Matching Engine</summary>
<br/>

A full-stack AI platform that scores resumes against job descriptions using true semantic similarity — not just keyword matching — with LLM-generated improvement feedback.

| | |
|---|---|
| **Stack** | Python, FastAPI, Streamlit, spaCy, Sentence Transformers, Groq (Llama 3), Supabase, WeasyPrint |
| **Scale** | Decoupled FastAPI scoring engine + Streamlit interactive frontend |
| **Performance** | Async FastAPI backend for concurrent scoring + LLM calls |
| **Security** | Supabase-authenticated user sessions with persistent score history |
| **Impact** | Combines embedding-based semantic scoring with LLM-grounded, explainable feedback and PDF export |
| **Repository** | [`View Source →`](https://github.com/Karan-desai-7299/ATS-Resume-Scorer) |

Uses Sentence Transformers to compute cosine similarity between resume and job description embeddings, layered with spaCy-based keyword extraction, then grounds Groq's Llama 3 output in the actual computed match data — producing feedback tied to measurable signals rather than free-floating LLM judgment.

</details>
